Privacy & data

What happens to your prototype data

A plain-language summary of the current implementation.

Scoped to the connected flow

ProtoVid scans prototype connections on the current Figma page and captures only the frames in the selected connected path. It does not scan unrelated files.

Sent when you export

Captured frames are used in the plugin for local MP4 encoding when supported. If fallback transcoding is needed, the plugin sends the fallback video payload to ProtoVid's encoding endpoint.

Review links expire

Creating a review link stores the MP4 and review metadata server-side. Free links are available for 7 days; paid links for 30 days. Expired links are no longer served.

The repository does not show an automatic database cleanup job after a link expires, so physical deletion timing and whether customer content is used for training require owner confirmation. Pro payments use Stripe; export and review data use ProtoVid's backend database.

Questions

A simple export path for client delivery and repeat design iteration.

Do I need to screen record?

No. ProtoVid captures connected prototype frames and produces an MP4 walkthrough directly from the plugin.

Can I try it before paying?

Yes. The Free plan includes 3 watermarked 720p exports each month so you can validate the workflow.

When do I need Pro?

Upgrade when you need 1080p or 4K output, no watermark, or unlimited exports for ongoing client work.

Can I share a review?

Yes. After exporting, you can create a browser-based review link with timestamped comments and approval or change-request status. Downloading the MP4 remains the core export path.
